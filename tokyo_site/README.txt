TOKYO WEBSITE
=============
index.html ist die Startseite.
Den Ordner "assets" zusammen mit index.html behalten.

Lokal: index.html im Browser öffnen.
Online: den gesamten Ordner bei einem Webhosting-Dienst veröffentlichen.

Funktionen:
- Sticky Navigation
- Smooth Scroll
- Bilder klickbar → Zoom (Lightbox)
- Quiz mit aufklappbaren Lösungen
- Scroll-Animationen für die Themen
